Why Saku?

✓

Speed

Built in Rust for instant feedback. No loading screens, no lag—just pure terminal velocity. Your tasks, notes, and workflows respond as fast as you think.

○

Ownership

Human-readable JSON storage. No cloud lock-in, no proprietary formats. Your data lives in simple files you can inspect, backup, and control. AGPL-3.0 licensed.

●

Focus

Minimal, composable tools that do one thing exceptionally well. Terminal-first design means zero distractions and keyboard-driven efficiency.

The Suite

tdo
○ ● ✓
Implemented

Task management that thinks like you do. Flexible scheduling modes (Today, Inbox, Upcoming, Anytime, Someday), Areas & Projects for organization, and lightning-fast Rust performance.

  • Flexible scheduling: Today/Inbox/Upcoming/Anytime/Someday/Logbook
  • Areas & Projects for hierarchical organization
  • Simple JSON storage with automatic backups

Get Started

Quick Start

# Install tdo
cargo install --path crates/tdo
# Try it out
tdo today

Requires Rust 1.83+ with edition 2024 support

Build From Source

# Clone the repository
git clone https://github.com/asierzapata/saku.git
cd tdo

# Build all tools
cargo build --release --workspace

Binaries will be in target/release/
